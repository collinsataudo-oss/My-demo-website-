KING DAVID ARTIST - RUNNABLE DEMO

A one-page responsive gallery demo made with HTML, CSS and JavaScript. No Python or Node required.


RUN IN TERMUX:
1) Copy the project folder to your Termux home directory.
2) Open Termux and run:
   cd ~/king-david-artist
3) Start a local server with:
   php -S 127.0.0.1:8080
   (If PHP is not installed, install it with: pkg install php)
4) Open your phone browser and visit:
   http://127.0.0.1:8080

Alternatively, if PHP is not installed, the HTML can be opened directly in a browser, though local-server mode is recommended.
